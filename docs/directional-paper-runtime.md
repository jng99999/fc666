# 独立双向研究模拟账户

入口 `/paper/directional`，API `/api/v1/directional`。与旧现货、黄金、PPO、连续 AI 草稿账户分别存储；不迁移或承接旧账本。所有响应 `RESEARCH_PAPER`、`trading_enabled:false`。没有私有交易 API、模型调用、杠杆、资金费、隔夜费或真实强平。

## 执行链路

单进程后台线程每10秒采集活跃账户相关产品的真实 bid/ask。加密使用 Bitget 现货订单簿，XAU/USD 使用既有 Swissquote AT/AT standard 报价，不用黄金代币替代。报价时间和接收时间分别校验。停止新风险但仍有持仓的账户继续采集并执行止盈止损；关闭网页不影响后台。

账户支持手动结构化 LONG/SHORT/FLAT 决策和自动 `SMA20_QUOTES` 基线。后者比较最近20条独立、有效的观察报价中间价与其均线，缺口超过行情时效会重置预热窗口；不等于20根闭合K线，也不等于 AI 或视频三条件策略。反向先减仓为零，再由后续独立决策开另一方向。

每次开仓必须有数量与 SL/TP；自动模式在创建时固定数量和保护比例。LONG 以 ask 买入、bid 平仓；SHORT 以 bid 卖出、ask 平仓，叠加账户明示的单边费率、不利绝对滑点和 tick 舍入。全额抵押、单仓、不加仓。提交不立即成交，只能使用严格晚于服务端接收决策时间的后续真实报价。保护在新决策和新闻检查前执行；跳空按实际报价，不能保证止损价成交。

## 消息门禁

服务器默认没有可完整验收的新闻源，因此未知、过期、来源不可信、覆盖不足和高影响窗口均禁止新仓。生产环境不注入测试空日历。客户端不能提交 quote、news、available_at 或更改被冻结配置。

可接入由操作者维护的服务端只读 `DIRECTIONAL_NEWS_FILE` 与 `DIRECTIONAL_NEWS_SOURCE`；必须提供原始观察时点、完整覆盖窗口、当时已知事件和确切产品范围。供应商配置不等于来源已合格。文件读取失败不续用旧“安全”结论，不重写快照时间。无真实新闻时本链路如实阻断，不宣称已取得真实新闻过滤后的收益。

## 保存与权限

`core/paper/directional_store.py` 使用独立 `.sqlite3`、WAL、FULL同步和 `BEGIN IMMEDIATE`。不可变操作与成交表、哈希检查点、请求编号和版本冲突共同保护持久性。普通行情只更新有界最新报价窗口，不消耗10,000次记账操作预算；达到预算只停新风险，保留已有仓位的保护退出。读接口不会采集或驱动成交。

浏览器使用 HttpOnly/Secure/SameSite会话，账户所有权由服务器校验；客户端不能真正保密，因此不存放交易或模型密钥。每个标签页独立保存当前账户选择。清除该会话无法恢复账户访问，不把此测试会话当完整用户登录系统。创建重试保持同一个请求编号；写入失败不盲重试，先核对服务端结果。多标签的交易状态变化会导致旧版本409，停止确认固定账户身份和版本。

## 运行与发布

新服务由 `infrastructure/directional.compose.yaml` 独立启动，只占用loopback18668，数据卷 `/opt/fc666-directional-test/data`，单worker。镜像由已验证API基础镜像派生，只复制独立服务/market/store/方向内核；不复制dirty settings、schema、migration0031或AI草稿。通过现有HTTPS站点的专用 `/api/v1/directional/` 路由转发。前端 `DIRECTIONAL_API_BASE_URL` 只配置服务器URL；不带任意客户端目标URL。

健康接口新增上游/代理来源标记与关联编号；200/503仍透传，超时或网络故障502，不用重试遮盖故障。历史503没有完整响应证据，不能用后续200倒推出原始根因。
