# 手机管理员与 AI 模拟配置

入口为 `/system/api`。密钥在浏览器提交过程中只存在于当前表单内存，经 HTTPS 发送到服务器后加密保存；不写入 localStorage、sessionStorage、静态网页或 Vercel 的公开环境变量。配置读取仅返回“已配置”标志，不返回原密钥。

## 首次使用

1. 由运营者通过私下的一次性初始化入口进入，自己设置用户名和密码。初始化凭证最长有效一小时，使用后失效，没有默认管理员密码。密码至少 12 个字符，UTF-8 编码最多 128 字节。
2. 在手机登录后填写服务商、准确模型名、可选接口地址和 API Key。没有默认模型。OpenAI 兼容接口、Anthropic 和 Google 使用对应 SDK；Google 暂只支持官方默认地址。
3. 新输入的密钥保存后从表单清除。刷新后输入框仍为空，“已配置”表示服务器保留；留空再保存会保留已有密钥。删除密钥必须勾选明确的清除操作。更换服务商或接口地址时，必须重新提供或明确清除旧密钥。
4. 新闻和黄金历史接口须符合页面内“接口契约”，普通新闻网页、报价页面和不同产品数据不能替代这些接口。没有有效新闻覆盖时禁止新增风险。
5. 先保存新闻来源，再以管理员身份创建 `AI_RESEARCH` 实时模拟账户。账户冻结自己的新闻来源标识，修改来源后应新建账户。勾选需要授权的账户并保存，再到账户页启用自动模拟。

登录会话最长八小时，闲置三十分钟失效。改密码后其他会话失效；退出会删除当前管理员 Cookie。退出本身不停止已经启用的服务器模拟计划，需到账户页暂停。

## 账户和自动模拟

管理员新建的账户绑定稳定的管理员身份，可换手机登录后继续查看。旧浏览器工作区、账户和账本保留；退出管理员可回到原浏览器工作区，不会自动迁移或删除旧账户。

保存任何连接配置前，会暂停已启用的 AI 计划、递增运行批次并取消未成交的待执行提案，避免旧模型结果在新配置下入账。已有持仓仍由独立行情循环执行保护性止盈止损。保存后需要重新明确启用自动模拟。

自动模拟依次检查模型和账户授权、行情时效、历史指标、新闻窗口、账户版本、资金和风险限制。模型只能提出 `LONG`、`SHORT`、`FLAT` 或 `HOLD` 候选；已有持仓不能直接反向开仓。通过校验的提案在后续有效报价上模拟成交，不把提案视为已成交。

高影响事件窗口、新闻缺失或过期时禁止开仓和加仓，保护性平仓继续。配置库不可读取也不能回退使用旧环境密钥。`LIVE_TRADING=false`，没有交易所实盘下单入口或实盘启用按钮。

## 服务与部署约束

- `FC666_OPERATOR_DIR` 位于账户服务的独立运行目录。身份库及会话密钥保持 700/600；加密 vault 可由指定服务组只读访问，目录及文件为 750/640，不改变已有文件 owner。
- 模型服务仅挂载 vault，且为只读；不挂载管理员身份库或账户数据库。部署前应使用实际账户服务用户预建目录，避免 Docker 自动生成不可写的 root 目录。
- 管理员代理只接受 HTTPS 上游，开发时允许 loopback HTTP；禁止 URL 内凭据、查询参数和片段。写请求要求同来源、JSON 和有界请求体；配置写入另外要求 CSRF 和版本校验。
- API 密钥通过加密存储提供给私有模型进程。OpenAI 与 Anthropic 使用实际 SDK 对应的 HTTP 客户端；连接验证所有 DNS 地址并固定目标 IP，保留 Host 与 TLS 名称，拒绝私网和重定向，关闭自动重试。
- 首次发放初始化凭证应在服务和网页验证后执行，私密文件交付，不进入聊天、日志或 Git。不得为浏览器验收提前占用真实管理员账号。

## 验证边界

`tests/test_operator_runtime.py` 验证真实身份、加密配置、账户授权和合成候选的模拟入账、配置变更暂停、新闻阻断及保护性平仓。`tests/test_provider_transport.py` 在锁定的 TradingAgents 环境和 worker 镜像中使用实际 SDK，但 HTTP 响应来自内存 fixture，禁止外部 socket/DNS；轻量账户环境缺少模型 SDK 时会显式跳过。

这些验证不等同于真实付费模型已经调用成功。用户提供服务商、模型并在站内配置 API 后，还需查看真实研究记录、风控结果、待成交提案及后续模拟成交回执；不得用固定候选冒充真实 AI 决策。
