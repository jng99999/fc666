# PostgreSQL local ownership acceptance

Schema0019 adds immutable requested_paper_claims and nullable ownership token/acceptance-clock event fields. The existing account row transaction now coordinates claim, expiry-only takeover, source receipt acceptance and settlement. Owner labels remain local coordination data, not authenticated identity. Claimed requests reject ordinary unfenced supported writes; initial enrollment requires controlled active zero-event history. Exact same-owner retries return the original lease without extending it. Current owner/token/expiry is checked before and after processing, so expiry rolls back event, source receipt, SUBMIT gate and balances. Tokens never override control/funding gates or permit external submission/retry.

Acceptance covers unique concurrent owners, same-owner retry and expiry reacquisition, old tokens even with reused labels, changed/conflicting simultaneous local SUBMIT, stable source acknowledgements after takeover, expiry during claim and source processing, unknown retained holds, STOP/late fills, zero-event void closure, malformed proposals/digests before storage, bounds/capacity, non-retrospective enrollment, immutable claim/event rows, missing claim fail-closed reads, resealed token/time/checkpoint/assessment tampering, database-independent CLI, populated downgrade refusal and genuine SIGKILL both before commit and after lost response for claims and owned source acceptance.
