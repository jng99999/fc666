# PPO 模拟研究目标与实施计划

日期：2026-10-22。沿用已确认的独立 PPO 实验方案；实盘关闭，旧账本不变。

## 目标与范围

实现真实历史数据→因果观测→PPO 训练→冻结模型→含成本策略对比→模拟接入资格检查的可复现链路。首期黄金 XAU/USD 1h，动作是目标权益仓位 0%、25%、50%，仅做多，不含杠杆。不安装整个 FinRL、不替换既有黄金 v3 引擎，不触碰尚未完成的 continuous-ai-paper 草稿。

方案比较：直接把 PPO 注册进 LONG/FLAT 接口不能表达动态仓位；重构全部账户接口会扩大数据风险。因此采用隔离研究环境，复用已验真的历史快照、Decimal 成本模型及既有策略作基准。使用 FinRL 同类的 Stable-Baselines3 PPO 算法实现，不宣称复制了基金策略或整套 FinRL。

## 顺序与完成条件

1. **实现研究环境与失败边界**：只观测已闭合柱，信号后第一个真实周期边界报价成交；缺报价/过期不补单；bid/ask、显式单边费用和滑点、0.01oz 步长、单笔 10oz；资金与持仓守恒。测试未来后缀不改变过去、无未来填补、现金不足、缺报价、非法动作及结束边界。
2. **冻结实验协议再训练**：2023 训练、2024 验证、2025 时间外评估；历史已被此前研究查看，明确不是全新的密封盲测。固定种子 7/19/42、相同训练预算及超参数，不按 2025 结果挑模型。特征只用历史收益、已闭合波幅、点差、时间缺口及账户状态；不以全样本拟合归一化。
3. **运行真实数据实验**：三种子，配置成本及两倍成本压力，与现有八策略、持有和现金基准比较；保存模型/数据/代码/依赖摘要、完整收据、动作分布与失败统计。奖励用净权益对数变化，风险另设准入门槛；不声称仅修改奖励即可保证风控。
4. **模拟接入门槛**：技术测试通过、三种子均非退化（两种以上动作且实际成交）、时间外配置成本净收益为正、压力成本不过度恶化、回撤不超过同口径持有基准；所有门槛及结果公开。任何失败均保持研究态，不自动接入旧账户或改用表现最好种子。新的持续前向模拟才是后续新证据。
5. **交付**：研究命令、结果与计划状态可核对；完成代码检查。测试站只展示真实已完成结果与资格状态，不启用未通过的策略。若资格不通过，明确阻止模拟账户自动下单，不为了“上线”放宽门槛。

## 部署与数据保护

训练只在本地隔离 Python 环境执行，RL 依赖不进入线上 API 或 Vercel 构建。模型不接受远程上传；可发布结果仅为 JSON 研究报告，不执行模型反序列化。发布测试站前执行相关前后端测试与构建，确认实盘关闭。正式生产及破坏性操作另行审批。

- [FinRL](https://github.com/AI4Finance-Foundation/FinRL)：训练、评估、基准与决策流程参考；其缺失值回填与股票成交环境不直接使用。

- [Gymnasium 自定义环境](https://gymnasium.farama.org/introduction/create_custom_env/)：观测、动作与终止语义。
