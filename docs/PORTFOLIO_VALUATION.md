# 独立实时Paper账户的只读场景估值

`/portfolio` 明确选择1..8个实时模拟账户，读取一次共同快照、计算资产/现金/盈亏与风险提示，并可下载完整输入和结果。它汇总的是各账户**独立的虚拟资金**，不是共享资金池或真实交易组合；历史Paper账户不纳入，没有转账、交易、重置、持仓合并或风控状态写入。

## 共同时间与数据

`POST /api/v1/portfolio/valuation` 接受唯一的实时账户UUID列表及Decimal字符串阈值，不接受客户端as_of。账户、规则、已接受行情和报价在一个PostgreSQL REPEATABLE READ事务中读取，避免行情或规则更新时混合版本。API在账户读取后记录服务器UTC采集时点，作为观察时间上界；事务数据仍来自同一数据库快照，不承诺所有账户来自某个历史秒的复原。

共同报价时点为采集UTC分钟的起点，即最后一个应闭合分钟的结束时刻。每个BTC/ETH Binance Spot USDT账户都必须有同一时点、同一instrument的公共1m闭合柱报价。数据库查询不读未来报价，同一instrument的多个账户使用相同报价。使用收盘参考价，不代表实际可成交报价；没有bid/ask、交易滑点或清算估值。

账户的冻结快照和持久账本先按既有版本重算核对；当前规则与已接受数据必须仍与冻结输入相符。BLOCKED账户不汇总。RUNNING/PAUSED账户若下一应闭合策略柱已到共同报价时点却未接受，则判定ACCOUNT_LAGGING。1h账户在下一小时闭合前不会仅因账本时钟较早而被误判落后。STOPPED/LIMIT_REACHED保留的库存可以按新公共报价重估，不恢复策略运行，不自动平仓。

任何账户或市场不支持、账本核对失败、规则或已接受历史改变/缺失、价格缺失/陈旧或账户落后，均返回逐账户原因及 `UNAVAILABLE`，totals为null且exposures为空。不能把缺失余额/行情当0，也不返回部分账户总和作为完整组合。分钟交界公共数据尚未到达时可能暂时不可估值，可稍后重新请求，不静默使用上一分钟替代。

未来激活、未来接受的柱/观察时间或未来报价不发布快照，返回409。历史账户或不存在的实时账户返回404；0/超过8/重复ID、客户端as_of、浮点阈值及超范围阈值返回422。当前环境无多用户鉴权，仍只绑定本机端口，不能据此部署公网多用户交易。

## 金额与提示

版本 `paper-portfolio-closed-minute-v1` 使用Decimal precision120，金额以字符串输出。单账户市值=库存×共同价格，权益=现金+市值，未实现盈亏=市值−成本，净盈亏=权益−该账户独立初始资金。合计现金/市值/权益/初始资金/费用/已实现与未实现盈亏；检查净盈亏守恒，容差只覆盖既有60位账本公式的微小舍入。BTC和ETH数量不相加，敞口按币种合并市值和数量，再除以完整总权益。

默认提示阈值：资产总市值/总权益大于0.8、单币种市值/总权益大于0.6；用户可输入0..1的精确Decimal字符串。超过阈值产生GROSS_WEIGHT或ASSET_WEIGHT，不阻止订单，不修改已冻结的账户限额。既有停止买入与实时worker心跳未确认也给出提示；worker不可用本身不是现金归零的理由，是否漏处理闭合柱单独判断。

没有组合回撤、Sharpe或相关性指标，不能将独立账户的历史峰值和不同时间曲线简单相加。当前提示不等于完整组合Risk验收，不能解锁实盘。

## 页面与复现

候选账户分页；翻页保留选择，最多8个，浏览器刷新仅恢复选择，旧估值不自动恢复。每次计算清除旧结果，失联或无效请求不会继续显示此前已确认总额；修改选择也会清除结果。结果明确列出本次采集时点、共同报价时点、每账户账本时钟及价格来源。改变阈值需重新计算；结果是固定快照，不随后台行情更新。

导出包含选择、阈值、实时账户已知预热/观察数据/持久账本、规则、当前接受数据对照、共同报价及worker心跳。没有历史Paper未到达价格。原始JSON与API响应一致；SHA256绑定所用输入，`scripts.verify_portfolio`在32MiB以内可离线重算并核对完整结果。只证明内部一致性，不证明交易所来源、数据库时点、用户身份或防管理员篡改；UNAVAILABLE报告的复现也不将受损账本标为已验证。

无需迁移、新依赖、秘密、域名或服务，head仍0008；五服务启动不变。下一切片是版本化场景定义和持久估值快照/查询历史；先冻结选择及资金边界，再考虑完整组合Risk与真正共享资金账本。Live仍关闭。
