# 黄金 PPO 首轮研究结果

2026-10-22。研究协议见 `ppo-research-plan.md`。本次实现参考 FinRL 的训练/评估流程，算法使用 Stable-Baselines3 2.7.0 PPO；没有把 FinRL 整套股票成交环境接入平台。

## 实际执行与结论

使用已有不可变 HistData 快照 `ee9afe981db266959ebcc1557e6120ae6e60012f761265ed46d57ab57878276c`，2023—2025 共16,940根完整1h柱；底层来源为此前归档的真实成对bid/ask tick。训练只传入2023前缀，2024验证，2025后续评估。该历史此前已被研究查看，因此不是密封盲测。

每个种子7/19/42固定131,072训练步、相同网络与超参数；CPU单线程。动作表示权益目标仓位0%、25%、50%，按已观测历史更新，下一边界真实报价成交，不能用未来缺失值填补。单边费用0.10 USD/oz、额外不利滑点0.05 USD/oz和原始点差；另有双倍成本压力。费用、额外滑点仍是假设，未包含掉期、融资与实际深度。

所有种子/窗口/成本场景均展示。共12项PPO评估，加上八规则策略、持有和现金基准各四项，合计52项。完整收据和模型留在任务输出目录；测试站只发布52,519字节的固定摘要，不上传或执行模型权重。

## 复现

训练依赖仅在独立环境安装，不进入API或前端生产依赖：

```sh
python3.12 -m venv /path/to/ppo-venv
/path/to/ppo-venv/bin/python -m pip install -r requirements-rl.txt
/path/to/ppo-venv/bin/python -m pytest tests/test_gold_rl.py -q
/path/to/ppo-venv/bin/python -m scripts.study_gold_ppo \
  --history /path/to/frozen-history \
  --dataset ee9afe981db266959ebcc1557e6120ae6e60012f761265ed46d57ab57878276c \
  --output /path/to/new-experiment-directory \
  --timesteps 131072 --commission .10 --slippage .05
```

输出目录必须不存在，不覆盖旧实验。输出包含预先写入的protocol.json、精确运行库版本、代码/数据/模型摘要、模型ZIP、本地JSON actor、全部收据与公开摘要。只加载自己刚生成的模型；网站不接收模型上传或执行反序列化。

本轮真实复跑的三个JSON actor与初轮逐字节相同，逐观测验证JSON actor动作等于原PPO动作。它验证的是当前CPU/库版本下的复现，不承诺不同平台训练权重逐字节相同。

## 已修复并验证的边界

- 固定仓位动作不能绕过提交上限，首版明确拒绝非50%上限配置；非法/NaN/Bool动作不交易。
- 缺/晚报价不补单，最后一根观测不触发窗口外成交；每步Decimal资金/盈亏守恒。
- JSON actor拒绝动作顺序变更、非有限数值及错误维度。
- 门槛要求完整唯一的三种子×两成本，拒绝重复种子、缺基准、NaN/Inf、非法回撤/成交数/动作计数；任一失败不能被平均收益掩盖。

实际本地输出：RL测试36 passed；现有黄金测试29 passed（Python3.11，两个既有弃用警告）；前端40 passed；TypeScript与Next构建通过。专用 `Isolated PPO research checks` CI安装CPU依赖并执行真实PPO合成测试；普通应用CI不安装训练依赖，缺依赖时的skip不当作RL验证通过。
