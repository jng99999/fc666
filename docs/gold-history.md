# 黄金历史回测与策略对比

## 数据来源与安全边界

[HistData FAQ](https://www.histdata.com/f-a-q/)明确：ASCII tick含DateTime/Bid/Ask/Volume，时间是固定EST、不随夏令时调整；M1只含bid，因此本功能不用M1文件伪造ask。下载使用其公开月度表单，不需要账户、凭证或付费。不存在数据保证或认证。本次旧Dukascopy接口返回429，新接口返回WAF challenge，停止尝试，没有绕过。

`scripts/import_gold_history.py`保存月度ZIP、SHA256、URL和逐月质量统计。CSV按UTC-05:00转换UTC。仅形成边界120秒内有报价、内部最大缺口不超过300秒的1h中间价OHLC；4h须四根完整连续1h。不生成虚构成交量或平柱。月度缓存绑定原始ZIP摘要与解码版本；数据快照为内容寻址gzip JSON，加载会核对摘要、价格、时序和覆盖。

2023年10月源文件发现回退近一小时的相邻记录。受影响小时被隔离并计数，不排序后假装连续、不猜测DST修正。其他无完整柱小时包括休市与无法解释的数据缺失；没有完整交易日历时不把它们全部认定为休市。回测只能代表完整观测子集，未知缺失可能影响信号和回撤。这不是完整经纪商交易日回放。

示例（结束月不包含，只允许已完成月份）：

```sh
python -m scripts.import_gold_history --start 2023-01 --end 2026-10 --output /path/to/gold-history
```

仅将验证过的 `<sha256>.json.gz`部署到 `GOLD_HISTORY_PATH`（默认黄金SQLite同目录下history），不上传原始大ZIP到Git/Vercel。目录接口公开数据质量，不公开任何会话或账户。历史HistData与实时Swissquote不同，不拼接为同源数据，也不把回测结果说成瑞讯实际表现。

## 策略、成本与时序

复用 `core/strategy/registry.py`八个固定版本：EMA、双SMA、RSI、Bollinger、Channel、MACD、ROC、Stochastic，默认参数由现有模型校验并冻结。来源/改编见既有 `research-strategies.md`和`research-matrix.md`。这些研究策略不等同于实时1m黄金SMA20账户，本次不声称重演该账户历史。

另外自动加入买入持有参考：同样初始现金、投入比例、步长、单笔上限及成本，首次合格报价买入后不再平衡。它是被动基准，不是新增可用于实盘的策略。每项独立USD资金，不能把各项收益相加为组合收益。

每根观测闭合中间价柱更新指标，价格与高低来自当时成对tick。指标跨休市/缺失延续已观测柱序列；若下一柱不连续或首个报价晚于信号120秒，取消旧意图，不用缺口后的价格追补。下一根连续柱第一条实际quote用于成交，买入ask、卖出bid；单边不利滑点USD/oz、额外费用USD/oz由用户设置。点差乘数1使用原始点差。0.01oz步长、10oz上限、投入≤0.5及1倍仅做多/空仓为研究约束，不声称是历史经纪商规格。

同时计算三种场景：无成本中间价参考；提交成本；两倍费用、滑点和点差压力。压力/零成本场景为反事实，不声称是历史真实费用。手续费/滑点没有历史经纪商成交单证，仅为显式假设；成交点差来自真实源tick。成本变化会影响数量取整与后续资金，净收益差不能简单归因为固定成本和。

现金、持仓、费用、成本基础、已实现及未实现盈亏使用Decimal并校验守恒。最后持仓不虚构强平，按适用bid估值；零成本用mid，压力用扩大点差后的bid。最后没有后继报价的信号保留为未成交。回撤为观测柱收盘权益回撤，不是逐tick/盘中最大回撤。没有融资、隔夜掉期、实际深度或可成交量模型。

统一暖机长度为所选策略最大需求与100柱中的较大值；有前置数据时用窗口前历史，没有时显式后移有效起始时间，所有策略共享同样的有效窗口。1h/4h各自独立暖机。完整窗口计算三成本场景，年度子窗口只计算提交成本。至少三个年份时，最后一年预标为holdout、前一年validation、更早development；不足三年只标descriptive。参数不自动优化。保留检验不是密封盲测，用户能看到并重复研究其结果，不保证真实样本外优势。

## 持久任务与接口

`gold_research_jobs`为追加的新表，沿用黄金会话归属与SQLite事务。既有accounts/events不写入、不迁移。UUID+规范化请求摘要保证幂等：同请求恢复同任务，改参数同UUID返回409。每会话最多两个未完成、全局八个；累计最多2000个研究，满时拒绝而不删除旧结果。单实例后台线程计算，GET无执行副作用。重启只重新排队未完成纯研究计算，不重放账户订单。

冻结窗口90天至5年，最多八个策略、两个周期，逐年度成员在入队前一并校验。每项导出≤3MB、总结果≤48MB，超限明确失败，不能静默截断。数据库存全部结果；概览含指标、部分绘图抽样，单成员接口含完整成交和抽样权益；结果清单保存数据与源ZIP摘要、请求、引擎版本、加载时代码SHA256和策略定义。图表抽样不参与指标或成交计算。

前端 `/gold/research`；后端 `/api/v1/gold/research/catalogue`、`runs`、`runs/{id}`、`runs/{id}/manifest`、`runs/{id}/members/{index}`。BFF严格白名单与同源检查、只传黄金Cookie。匿名账户/研究没有跨设备自动找回；不能把客户端选择或缓存当作授权。

UI提供排队进度、失败说明、同UUID显式重试、刷新恢复、按策略/成本/年份对比、权益图、逐笔分页及CSV/JSON。年度只提供提交成本，切换年份时界面强制显示该可用场景，防止选择框与结果筛选不一致。沿用Apple控件、底栏与手机安全区。

验证：`pytest tests/test_gold_research.py tests/test_gold_paper.py -q`、前端Node测试、TypeScript/构建、真实历史完整矩阵、线上API与浏览器。覆盖成本守恒、前缀时序、缺口不追补、所有策略、非法/损坏数据、跨会话、并发幂等、任务失败与恢复。实盘始终关闭，研究任务没有晋升或切换实盘入口。
