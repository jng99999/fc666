## 边界与下一目标

这是有界闭合柱实时模拟，不是交易所实盘或逐笔撮合。延迟阈值/容量和滑点是明确假设，不证明参考价格可成交。没有完整OMS、组合风险、鉴权、账户列表/控制签名审计、保留清理、长时性能或灾难恢复验收。每账户最多1000根、最多20个运行/暂停账户；停止不平仓。离线核对证明内部一致性，不证明行情来源或观察/控制操作真实性。实盘关闭。
