# 研究模块交付状态

核对日期：2026-10-14。以下是当前开发分支的实际能力，不代表公网测试站已更新，也不代表整个平台完成。

| 能力 | 当前行为 | 限制 |
| --- | --- | --- |
| 内置策略回测 | EMA / SMA 现货做多或空仓；已收盘柱决策，下一柱开盘模拟成交；费用、滑点、数量步长和参与率进入计算 | 固定注册策略；不支持杠杆、卖空、真实下单或历史规则变化重建 |
| 研究任务 | PostgreSQL 冻结数据/规则/配置；任务租约、取消、过期接管、进度和结果保留 | 单次 2..1000 根连续已收盘柱；20 个活跃任务；输入快照上限 4 MiB |
| 参数批次 | 2..8 项共享历史和规则快照；整体入队或拒绝，成员独立计算 | 比较结果是样本内描述，不自动推荐获胜策略 |
| 留出测试 | 固定参数按时间切分；两段资金、指标和状态独立 | 不训练参数；反复调参会污染留出样本 |
| 滚动寻优 | 训练窗口比较候选，按训练收益选参；网格顺序确定平局；独立测试窗口 | 每轮 1..8 候选，最多 8 轮；不拼接独立资金收益；不是统计盈利保证 |
| 在线复验 | 从冻结输入重算完整报告并比较规范化 JSON；页面有独立复验按钮 | 验证保存报告的一致性，不认证数据来源；不校验浏览器绘制结果 |
| 离线复验 | 普通/留出报告支持严格文件读取、完整重放和旧版兼容；滚动报告另有校验工具 | 普通/留出文件上限 4 MiB，滚动上限 32 MiB；需本项目环境 |
| 异常任务恢复 | 损坏或超限快照拒绝，不发布结果；后续正常任务继续完成 | 数据库故障仍需租约恢复；不等同基础设施灾难恢复 |

## 还没有完成

1. 通用策略 SDK 生命周期、版本化状态恢复和跨回测/回放/Paper 模式的一致执行。
2. 用户自定义策略的独立受限运行环境；不能把 Python 导入限制当安全沙箱。
3. 更广的交易品种、撮合模型和历史数据质量/覆盖证明。
4. 更广的优化方法和有明确统计方法的评估。已有滚动网格搜索不覆盖全部研究需求。
5. AI 研究解释、真实证据引用、模型版本记录、校准和历史时点隔离；目前设计文档标为 Not Implemented。
6. 公网部署后的完整 HTTP、真实行情 WebSocket、任务完成、浏览器复验和访问控制验收。

## 接下来执行

先落地固定内置策略的版本化生命周期和状态重放合同，在隔离测试中验证恢复后信号一致、未来数据不可见及模式间的一致性。随后接入研究引擎，保留现有引擎版本和旧报告重放能力。自定义代码沙箱与 AI 作为独立交付项，不能借该合同的通过宣称完成。

公网交付仍需要可调用的部署工具、已确认的 HTTPS 后端和实际部署验收。云环境健康、代码推送及本地构建不能替代这些证据。Live 保持关闭。
