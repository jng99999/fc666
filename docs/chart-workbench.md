# 价格结构与绘图工作台

入口：行情 `/`、分析 `/analysis`、黄金 `/gold`、历史回放 `/replay`。沿用同一主源码及现有 Lightweight Charts；没有引入依赖、复制第三方策略代码或修改交易执行器。

## 操作与边界

- 打开“绘图工具与图层”，选择水平线、趋势线、价格箱体、三点平行通道或斐波那契，依次点击主图锚点。可吸附 OHLC、取消、撤销/重做。
- “区域依据与绘图管理”提供确认时间、规则、状态、触碰次数；手动图形可修改名称/坐标、锁定/解锁和删除。JSON 导入导出按产品、行情源和周期严格隔离；绘图仅保存在本机。存储失败明确提示，坏记录不会在加载失败时自动清空。
- 自动标记只接收闭合柱。拐点延迟两柱确认；固定箱体边界、供需/OB 候选、三柱 FVG、BOS/CHoCH、趋势/通道、流动性事件均记录确认时点。历史缺口重置结构，不能把未覆盖时间补成连续行情。图形是明确规则的研究结果，不证明真实机构订单或盈利优势。
- 默认每类显示最新区域，选择较早区域时可额外显示。UTC 日/周参考需完整覆盖；会话采用当地 IANA 时区并处理夏令时。
- 成交量分布仅对真实成交量做最近 256 柱、32 桶 OHLCV 估算，显示 POC 与 70% VAH/VAL。没有逐笔主动买卖量；黄金报价采样没有真实成交量，明确不可用。
- 分档计划可编辑多空、数量、入场、止损止盈和成本。有效计划价格线绘于主图；不会提交或修改订单。成本、点差和滑点均是显式研究假设。
- 四策略比较为箱内反弹、Donchian 突破回踩、假突破收回及趋势回撤，最多 500 个当前加载闭合柱、固定数量、前序信号/下一开盘成交、70/30 时间留出。同柱双触发先止损，跳空采用更不利开盘；退出权益回撤不代表持仓期最大回撤。短窗口不等于长期验证，合成空头不代表现货可卖空。
- 只读 directional 账本按单一产品汇总成本、净敞口与压力。USD 黄金和 USDT 加密分开，不混入旧现货/黄金账本。刷新失败清除旧图层；不创建或停止账户。现有 1× 全额抵押引擎没有维持保证金和强平模型，因此不生成真实全仓强平价。
- Bitget 公共 USDT 合约 OI/资金费率只在点击时加载，严格核验产品/来源/时间，120 秒标记过期。黄金不适用；它不是现货成交量，也不进入历史回测。接口依据：[Bitget 官方公开接口](https://www.bitget.com/docs/catalog/market/derivatives)。
- 回放只传已到达前缀，不加载当前账户和实时合约快照。手动画线是用户研究笔记，不能视为历史上已知的自动信号。
- 所有新增计算仅用于图层和研究，不连接自动下单。实盘保持关闭；没有修改 API 密钥、管理员登录、账本或服务器执行配置。

## 关键源码

- `apps/web/lib/price-action.ts`：闭合柱事件流与估算成交量分布。
- `apps/web/lib/chart-coordinates.ts`：使用实际图表价格/逻辑坐标转换，随缩放和拖动投影。
- `apps/web/lib/chart-drawings.ts`：绘图校验、来源隔离和持久化格式。
- `apps/web/components/chart-workbench.tsx`：交互、图层、导入导出及图形管理。
- `apps/web/lib/chart-scenarios.ts`、`components/chart-scenario-panel.tsx`：计划、四策略比较、只读模拟持仓。
- `apps/web/lib/chart-derivatives.ts`、`app/api/market/derivatives/route.ts`：固定官方域名的无凭证公共请求。
