# 固定参数分段研究契约

POST /api/v1/research/holdouts接收base（原RunRequest）与严格整数train_bars。先一次读取最多1000根连续闭合历史及当前规则，再按时间顺序拆为前train_bars根样本内和其余样本外。分界为第一根样本外柱的open_time；样本内end等于该分界，不包含任何样本外柱。切分与数据/规则/请求进入原不可变后台任务快照。

每段至少有策略lookback+1根，以允许预热成熟后的下一柱成交：EMA lookback=period，SMA lookback=slow。非法切分或任一段不足返回409且不入队；非严格整数或超界请求422。未自动选择切分，也未训练/挑选参数；两段使用同一份提交时规范化strategy/parameters/config。

策略边界策略cold-start-independent-v1：分别调用两次全新Spot v3模拟，初始资金相同且独立，库存为0，EMA/SMA/regime状态与待执行信号均不继承。没有区间外预热数据；每段自身预热期保持空仓，资金收益为0。这些期内空仓柱仍计入该段完整观察时长与收益波动样本，未删掉它们以美化年化指标。样本内最后信号不在样本外开盘成交，样本内期末仓位不转移、不强制清仓，各段按自身最后收盘价标记。

两段分别显示收益、回撤、Sharpe及期末持仓。两段独立资金，禁止相加收益或拼接账户权益；未提供虚构聚合账户。若需要一个连续交易账户的walk-forward过程，必须另定义状态与资金继承语义。

后台仍使用原持久job、全局20活动容量、进度、取消、租约/3次恢复协议。train/test进度映射到全部柱数，只有两段成功后一次提交复合结果；任一段取消、失去租约或失败都不发布部分结果。停止后按同一快照重算，后续数据库历史变化不修改已接受输入。

复合引擎spot-holdout-v1：完整导出包含根dataset/manifest和两份完整v3 child exports。root manifest记录固定策略/参数/config/规则、全数据SHA、柱数/分界、子run_id与边界策略；root run_id为清单SHA。离线复现重建两段并逐字段比较完整结果；两份子导出也能分别通过原v3复现。v1/v2/v3原复现和旧任务分派未改变，未来更改v3公式时必须保留对应分段版本依赖。

网页“样本内 / 样本外分段研究”使用上方策略和配置；训练柱数默认60，历史默认120，实际范围/参数以结果清单为准。独立localStorage保存最后分段任务UUID，刷新恢复；最近20个总任务中属于holdout的任务可在分段记录恢复，原单策略记录过滤复合任务以避免误读结果。原任务GET/result/cancel接口保留；代理只增加holdouts提交入口，不允许任意上游路径。

限制：不训练、不自动寻优、不承诺留出样本没有被人看过；反复观察样本外结果再调参仍会造成污染。未实现多折walk-forward、滚动参数再训练或统计显著性验收。原成交量容量仍为研究代理，规则为当前规则快照，不是历史交易所规则重建。实盘关闭。
