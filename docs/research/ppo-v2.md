仅新增研究代码；复用冻结 GoldEnv 执行与 PPO 超参数，v1 不变。

训练仅 2023，验证仅已查看过的 2024；2025 不评价、不据其调参。A 原始输入；B 仅 2023 的 5038 个决策观测拟合七维 mean/std 后冻结；C 同 B 后前七维置零，保留内生账户状态。每臂种子 7/19/42，131072 步，共九次。固定成本手续费 0.10、滑点 0.05、spread multiplier 1；双倍成本测试不重训。固定 0/25/50% 在同 GoldEnv 再平衡，额外保留只买一次持有参照。

H1 初步支持须同时：B 至少两个种子的次常用动作占比 >=5%；三种子 B-A 配置成本净收益差中位数 >0；B 回撤中位数不高于 A；B 压力收益中位数非负。
H2 额外行情价值须：B 在两个成本场景全部三个种子上，收益均超过对应 C 和固定三基线最佳收益，回撤均不超过对应 C 及该最佳固定参照。任何失败均不宣称通过。三种子不做统计显著性结论。
