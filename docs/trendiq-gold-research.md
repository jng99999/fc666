# Trend IQ 与黄金模拟接入研究

核查日期：2026-10-20。对象由用户确认为 trendiq.net，黄金确认为独立 XAU/USD。

## 能借鉴什么

[Trend IQ 官方首页和FAQ](https://trendiq.net/)公开介绍截图识别、形态、支撑阻力、趋势线、多周期观察、参考入场/止盈/止损及Copilot。FAQ明确说它帮助分析，不自动执行交易，也不保证准确率。官网功能描述不能证明实际盈利，本次未购买或进入其付费分析引擎。

可借鉴的是“图上证据→条件→失效点→风险解释”的分析流程。本项目不能仅增加几个指标或AI说明就声称实现自动交易；还需要服务端持续运行、数据时序、资金检查、幂等执行和可核对账本。

[其隐私政策](https://trendiq.net/privacy-policy/)说明图表和附件会发送到第三方AI服务。我们本次不上传用户图表、不调用它的私有接口，也不复制其专有引擎。未来接AI时应使用明确的数据快照与结构化决策，模型输出必须经过服务端规则校验。

## 当前代码揭示的问题

1. 旧加密实时流 `core/paper/streams.py` 具有累计1000柱上限，达到后是 `LIMIT_REACHED`；这不等于可以无限持续自动交易。本次保留原账户、旧账本及尚未完成的AI草稿，没有把黄金塞进旧USDT现货契约。
2. AI服务商/模型尚未配置，不能制造“AI已下单”的状态。黄金首版明确使用手动模拟或SMA20规则基线；其目的为验证持续执行链路，不是证明策略收益。
3. XAU/USD不能与XAUT/PAXG代币、Bitget黄金永续合约混为同一资产。新模块用独立USD、金衡盎司和服务器账本。

## 黄金本次实际实现

使用[瑞讯公开报价](https://forex-data-feed.swissquote.com/public-quotes/bboquotes/instrument/XAU/USD)，固定AT/AT平台及standard档；公开接口当前能返回带源时间戳的bid/ask。它不是用户经纪商的可执行账户。[瑞讯贵金属产品介绍](https://www.swissquote.com/en-row/private/trade/products/forex/precious-metals)仅用来核对产品背景，不把不同实体的交易时间或合约规格套给此报价。

服务端每约10秒采样，完整一分钟采样柱闭合后才参与SMA20；缺口不补造。意图形成后最早下一条晚于实际观察时刻的新报价成交，过期不追补。买入参考ask、卖出参考bid，加显式研究成本；现金、库存、费用用Decimal计算。SQLite持久卷与不可修改的事件收据独立于旧数据库。

页面包含报价、采样走势、预热/规则状态、账户创建切换、模拟买卖、暂停恢复及分页账本，沿用Apple控件及手机底部安全区。实盘始终关闭。
